I built ClaudeMon to collect official AI product changes and service incidents in one place. Every change keeps its original source link.

The public JSON API exposes changes, incidents, sources and source freshness. Atom, RSS and JSON feeds let other tools subscribe to the same information. Public reads work without an API key.

Source freshness is visible alongside the updates so readers can see when a source is behind.
