## Fidelity review

The generator did not obey every constraint. Do not copy these discrepancies into
the product:

- Several images omit the approved wordmark brackets, substitute generic icons,
  widen the sidebar or introduce a different selected-row treatment. Keep the
  actual shared shell as the reference.
- Publication and Loops invent navigation across all three workspaces. The
  sidebar must show only the selected workspace. There are no newly approved
  Media, Redirects, Calendar, Tasks or Deployments destinations.
- The palette invents numbered navigation shortcuts. Keyboard shortcuts must be
  deliberately specified, implemented and tested; generated labels are not a spec.
- The sidebar image includes invented projects, statuses and old fixture dates.
  These do not represent Ani's records or the actual editorial schema.
- Life images are proposed connected compositions using fictional records.
  They do not prove that Life can read PersonalContext. Knowledge, Timeline and
  contextual projections remain dependent on supported owner capabilities.
- Observations, hosts, times and revision numbers in concepts are illustrative.
  Production must derive all of them from actual source evidence.

Use the images to judge composition. Use the playground to exercise geometry,
state changes and navigation. Use the implemented app and authenticated tests to
verify actual behavior. None of these studies authorizes copying personal text
into public storage or publishing an existing draft.

## Suggested review order

1. Playground Content → Review, then Publication; compare split and unified diff.
2. Open Search and type, clear, use arrow keys and Escape; its geometry should stay stable.
3. Compare desktop/tablet/mobile, expanded/collapsed navigation and light/dark.
4. Operations → Machines/Loops; compare unavailable and stale example states.
5. Life → People/Knowledge/Sources and a record's Evidence/Context view.
6. Catalog → Components/States/Interaction/Architecture to check shared behavior.

The playground's controls only change fictional fixtures. Refresh, Publish and
session examples make no network requests or real changes.
